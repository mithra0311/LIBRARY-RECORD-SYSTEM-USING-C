# 📚 Library Management System

A console-based **Library Management System developed in C** that allows users to manage book records efficiently.

### Features

* ➕ Add a new book
* 📖 View all books
* 🔍 Search for a book by ID
* 🗑️ Delete a book
* 💾 Store and manage records using file handling

### Concepts Used

* C Programming
* Structures
* Functions
* File Handling
* `fscanf()` / `fprintf()`
* CRUD Operations
* String Handling

**Language:** C
